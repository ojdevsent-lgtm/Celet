# Celet — Business OS

Celet is a modern workspace for managing customers, products, invoices, appointments and revenue from one dashboard.

## Current build
The first product foundation is live in the repository: responsive SaaS dashboard, business navigation, KPI cards, revenue visualization, recent activity, transaction table, customer search, empty states and quick-action modal workflows.

## Stack
- React + TypeScript
- Vite
- Firebase-ready architecture
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
